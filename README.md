# ezlol（东南亚服 · 海克斯乱斗专用 · 简体中文）

基于 [aarlint/ezlol](https://github.com/aarlint/ezlol) 改造，**只做海克斯乱斗（ARAM Mayhem）**：

1. **出装推荐**：海克斯乱斗的出门装、核心三件套（按购买顺序）、鞋子、后期装，数据来自 [aramkit](https://aramkit.com) 的海克斯乱斗对局（拿不到时退回 op.gg 普通大乱斗数据）。选英雄锁定后、进游戏后自动切到你在玩的英雄。
2. **强化推荐**：出现强化选择时自动识别屏幕上的三个选项，综合打分并给出理由：
   - **这个阶段**（开局 / 7 / 11 / 15 级）选它的胜率，和英雄平均胜率比；
   - 和**已选强化的组合**胜率；
   - **你现有装备**配这个强化的胜率变化；
   - 和第二名的差距、选它后的主流出装、是否需要转出装。
3. **强化 × 出装**：按你选的强化 + 已有装备推荐**下一件**和**核心出装**；游戏外点强化列表可预览。
4. **游戏内小窗**（全屏用）：总在最上层、点击穿透、不抢焦点、截屏时不可见。强化选择时自动弹出（三个选项按屏幕从左到右编号 1/2/3），选完显示记录的强化和下一件装备。默认在左下角，设置里可改位置、可预览。
5. **全局快捷键**（全屏下不用切出游戏）：
   - `Ctrl+Shift+1 / 2 / 3`：标记实际选的是第几个（不按默认记为推荐的那个）；
   - `Ctrl+Shift+H`：显示 / 隐藏小窗。设置里可以改键。
6. **测试日志**：每次识别读到的文字、截屏方式、匹配结果、推荐理由、记录的已选强化都写进本机日志（可选同时存截图），设置里一键打开日志文件夹。

已删除：召唤师峡谷、斗魂竞技场、符文、召唤师技能、加点、Riot API key，以及原版的自动接受、选英雄分析、游戏内记分板等。

## 安装

在本仓库的 **Releases**（或 Actions 里最新一次构建的 Artifacts）下载 Windows 安装包 `ezlol-…-win-x64.exe`，或免安装版 `…-portable.exe`。
安装包没有数字签名，Windows 会弹 SmartScreen 提示：点「更多信息 → 仍要运行」。

先开还是先开英雄联盟都可以，它会自己连上客户端。

## 强化识别与全屏

- 截屏用 Windows 的「桌面复制」接口（和 OBS「显示器捕获」同一种方式），只读屏幕画面，不碰游戏进程；失败时退回普通截屏。
- **全屏模式**：Win10/11 默认开着「全屏优化」时，截屏和小窗都能正常工作。请在 `Game\League of Legends.exe` 上右键 → 属性 → 兼容性，确认**没有**勾选「禁用全屏优化」。
  如果截到的是黑屏，小窗和面板会直接提示；这时只能改用「无边框」模式（看起来和全屏一样）。
- 需要 Windows 安装了**简体中文的「光学字符识别」**（设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项）。中文系统一般自带。
- 游戏客户端语言用简体中文；英文客户端也能认（同时匹配中英文名字）。

## 关于风控

程序只做这几件事：读英雄联盟客户端和游戏内的官方本地接口（op.gg、Blitz 等工具也在用）、截取屏幕画面（不注入游戏）、对截图做文字识别、注册普通的全局快捷键、显示一个置顶窗口。
它**不读写游戏内存、不注入、不改游戏文件、不模拟键盘鼠标**。风险很低，但没有任何第三方工具能保证零风险，请自行判断。

## 东南亚服说明

出装和强化数据都是 aramkit / aramgg / op.gg 的全球数据，和服务器无关，不需要任何设置。

## 自己打包

推送到 GitHub 后，`.github/workflows/build.yml` 会自动构建 Windows / macOS 安装包（在 Actions 页面的 Artifacts 里下载）。
推送一个 `v` 开头的标签（例如 `v2.0.0`）会自动发布 Release；程序的自动更新会跟随**你自己仓库**的 Release，不会被原版覆盖。

```bash
git tag v2.0.0
git push origin v2.0.0
```

本地构建需要 Go 1.26+ 和 Node 22+：

```bash
make build      # 构建界面并生成 bin/ezlol
./bin/ezlol     # 在 http://127.0.0.1:7331 打开
```
