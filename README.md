# ezlol（东南亚服 · 海克斯乱斗专用 · 简体中文）

基于 [aarlint/ezlol](https://github.com/aarlint/ezlol) 改造，**只做海克斯乱斗（ARAM Mayhem）**：

1. **英雄出装（游戏外：大厅、选英雄时）**：海克斯乱斗的出门装、核心三件套（按购买顺序）、鞋子、后期装，数据来自 [aramkit](https://aramkit.com) 的海克斯乱斗对局（拿不到时退回 op.gg 普通大乱斗数据）。选英雄锁定后自动切到你的英雄。进游戏后只显示按强化的出装（见 3）。
2. **强化推荐**：强化选择界面打开后按 `Ctrl+Alt+S`，识别屏幕上的选项，综合打分并给出理由（只在按键时截屏，不在后台截屏）：
   - **这个阶段**（开局 / 7 / 11 / 15 级）选它的胜率，和英雄平均胜率比；
   - 和**已选强化的组合**胜率；
   - **你现有装备**配这个强化的胜率变化；
   - 和第二名的差距、选它后的主流出装、是否需要转出装。
3. **按强化出装**：记下你选的强化后，按强化 + 已有装备推荐**下一件**和**核心出装**；识别时每个选项下面也会显示「选它后出装」。游戏外点强化列表可预览。
4. **游戏里怎么看**：游戏是独占全屏，ezlol 不往游戏上叠窗口。选强化时按 `Ctrl+Alt+S`，然后切出来（Alt+Tab）在 ezlol 窗口里看推荐；游戏中窗口只有两块：「强化推荐」（三个选项按屏幕从左到右排列，标出推荐的那个）和「按强化出装」。
   - **语音播报（可选，默认关）**：设置里打开后，识别完会念「推荐中间的，大法师」，记下强化后念下一件装备，不用切出来。用 Windows 自带的中文语音，不联网。
5. **全局快捷键**（全屏游戏里也能用）：
   - `Ctrl+Alt+S`：**识别强化**。强化选择界面一打开就按，截一张图识别并给出推荐。认不全且开了 AI（下面 C）时，自动把文字交给 AI 推断；
   - `Ctrl+Alt+1 / 2 / 3`：选完按，记下实际选的是左 / 中 / 右哪个，出装按它推荐。不按的话，90 秒后或到下一个强化等级时记为推荐的那个，之后也能在窗口里点「不对？」改；
   - 设置里点一下按钮、再按下新组合键就能改键；被别的程序占用会直接提示。不用 `Ctrl+Shift`：中文 Windows 里它会切换输入法，游戏里可能卡住按键。也可以设成 F7、F8 这类单键。
6. **AI 辅助（DeepSeek，可选）**：设置里填自己的 [DeepSeek API key](https://platform.deepseek.com/api_keys) 后可用，胜率数据仍是主推荐，AI 只给第二意见。三项可以分别开关，设置里显示本月估算花费：
   - **A. 选强化时复核**：识别到强化后，把英雄、装备、双方阵容、三个选项和胜率数据发给 AI，几秒后显示「AI 同意」或「AI 建议改选某个」及理由。每次不到 0.1 美分。
   - **B. 联网整理攻略**：进游戏后 AI 联网搜索这个英雄的乱斗玩法，结合胜率数据写一张攻略卡（优先拿 / 尽量别拿的强化、出装思路、来源）。每个英雄每个版本一次，缓存 3 天，不到 1 美分；游戏外要点「生成攻略」才会花钱。
   - **C. 识别不准时用文字推断**：屏幕读到了文字但对不上强化名（错字、漏字）时，把识别出的文字和相近的候选强化名发给 AI 推断是哪几个。**只发文字，不发截图**，每次不到 0.1 美分。AI 推断出的选项会标注「可能不准」。
   - key 只存在本机，只发给 `api.deepseek.com`，日志里不会出现。
7. **测试日志**：每次识别读到的文字、截屏方式、匹配结果、推荐理由、记录的已选强化都写进本机日志（可选同时存截图），设置里一键打开日志文件夹。
8. **上传日志到 GitHub（测试用，之后删除）**：设置里填一个只对本仓库有 Contents 读写权限的令牌，可以手动或每局结束自动把日志和最近的截图上传到 `test-logs` 分支。代码在 `internal/logupload` 和 `internal/api/upload.go`，测试结束后连同设置项一起删掉。

已删除：召唤师峡谷、斗魂竞技场、符文、召唤师技能、加点、Riot API key，以及原版的自动接受、选英雄分析、游戏内记分板等。

## 安装

在本仓库的 **Releases**（或 Actions 里最新一次构建的 Artifacts）下载 Windows 安装包 `ezlol-…-win-x64.exe`，或免安装版 `…-portable.exe`。
安装包没有数字签名，Windows 会弹 SmartScreen 提示：点「更多信息 → 仍要运行」。

先开还是先开英雄联盟都可以，它会自己连上客户端。

## 强化识别与全屏

- 截屏用 Windows 的「桌面复制」接口（和 OBS「显示器捕获」同一种方式），只读屏幕画面，不碰游戏进程；失败时退回普通截屏。
- **独占全屏**：截屏用「桌面复制」，读的是显卡送到显示器的画面，全屏游戏一般也能截到。如果截到黑屏，识别时会用语音直接告诉你。
- 需要 Windows 安装了**简体中文的「光学字符识别」**（设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项）。中文系统一般自带。
- 强化名按**东南亚服的简体中文**（`zh_MY`，和国服 `zh_CN` 的叫法大多不同，例如「返璞归真」/「回归基本功」）匹配，国服叫法和英文名也会一起匹配；英雄和装备名也用东南亚叫法。
- 识别规则：只在你按 `Ctrl+Alt+S` 时截屏一次，读到两个以上强化名就给推荐；过了加载画面才能识别；同一级重复识别会替换之前的记录。
- ezlol 自己的窗口在截屏里不可见（截图工具里会显示为黑色），避免把它上面的强化名读成强化选择。

## 关于风控

程序只做这几件事：读英雄联盟客户端和游戏内的官方本地接口（op.gg、Blitz 等工具也在用）、截取屏幕画面（不注入游戏）、对截图做文字识别、注册普通的全局快捷键、显示一个置顶窗口；开了 AI 辅助时，把识别出的文字和数据发给 DeepSeek。
它**不读写游戏内存、不注入、不改游戏文件、不模拟键盘鼠标**。风险很低，但没有任何第三方工具能保证零风险，请自行判断。

## 东南亚服说明

出装和强化数据都是 aramkit / aramgg / op.gg 的全球数据，和服务器无关，不需要任何设置。

## 自己打包与发布

推送到 GitHub 后，`.github/workflows/build.yml` 会自动构建 Windows 安装包（在 Actions 页面的 Artifacts 里下载）。

**发布新版本**：把 `electron/package.json` 和 `web/package.json` 里的 `version` 改成新版本号（比如 `2.0.1`），合并到 `main`。
构建完成后会自动创建标签 `v2.0.1` 和对应的 Release；这个版本号已经发布过的话，推送到 `main` 只构建、不发布。
推送一个 `v` 开头的标签也会发布。程序的自动更新会跟随**你自己仓库**的 Release，不会被原版覆盖。

本地构建需要 Go 1.26+ 和 Node 22+：

```bash
make build      # 构建界面并生成 bin/ezlol
./bin/ezlol     # 在 http://127.0.0.1:7331 打开
```
