# 海克斯乱斗避坑：网上能找到的反馈（2026-11 整理）

强化的中文名是按英文名对照的，游戏里东南亚服的叫法可能不同，括号里是英文原名。

网上没有一份「哪些英雄配哪些强化是坑」的完整清单，能找到的大多是官方补丁说明里**已经修好**的问题，
和零散的玩家吐槽。所以 ezlol 的避坑主要靠对局数据（见 [避坑清单.md](避坑清单.md)），这里记下网上的反馈，方便核对。

## 已在补丁里修复（新版本里不再是坑）

| 补丁 | 问题 |
| --- | --- |
| 26.6 | 赛恩带【溢流】(Overflow)时，被动形态下不能放技能 |
| 26.9 | 部分英雄用强化普攻触发不了【射手法师】(Marksmage)；霞和厄斐琉斯可以无冷却地连续触发【能量再充】(ReEnergize) |
| 26.11 | 伊泽瑞尔 Q 触发不了【台风】(Typhoon) |
| 26.14 | 【燃烧利息】(Combusting Interest)拿不到持续伤害（达瑞斯、提莫、图奇等）带来的金币 |
| 26.19 | 【疯狂科学家】(Mad Scientist)同时给了 30% 攻击力和 30% 法强，而不是 30% 适应之力 |
| 26.20 | 极光 Q 拿不到【神射手】(Skilled Sniper)的技能急速；卢锡安 W 中途放 E 时【法术分裂】(Spellsplit)不分裂；慎回响施法的 E 在闪现或预输入时不冲刺 |
| 6 月热补丁 | 暴击类强化（宝石手套、关键暴击、会心防御、暴击飞弹）刷不出来 |

另外有几个强化曾经因为 bug 被直接禁用（灵魄炸弹、魄罗冲锋、位面转移、主玩辅助、虚空冲刺），后来版本可能已恢复。

## 机制上的特殊情况（官方说明）

- 卡莉丝塔拿【冲刺】(Dashing)时，改为获得 125% 额外攻速（不是失效，是换了效果）。
- 官方强化列表注明：莎弥拉在大招期间不能使用 Inferno Trigger（和她大招同名的那个强化效果）。
- 【蜜蜂来袭！！！】(BEES!!!)要求**技能命中敌方英雄**才会扔出蜂巢（冷却 15→10 秒），主要靠普攻、技能很少直接打到英雄的英雄很难触发。

## 玩家反馈（未经官方确认）

- 莎弥拉拿【弱点】触发不了效果（ezlol 用户反馈，已内置为「坑」）。
- 技能海克斯（强化某个技能的强化）的任务不进度：瑞兹强化 Q、奎桑提 W 的威能升级；劫 W 连按触发不了「位移生成虚空区域」的海克斯。
- 3.0 版本的技能强化符文 bug 较多，部分强化之间效果互相矛盾。
